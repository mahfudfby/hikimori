HIKIMORI WEB 2.0 — PANDUAN SINGKAT
==================================

1) Install Node.js LTS dari https://nodejs.org
2) Windows: double-click INSTALL_WINDOWS.bat   |   Mac/Linux: bash INSTALL_MAC_LINUX.sh
3) Browser terbuka di http://localhost:3000

MENGUBAH ISI WEBSITE (tanpa coding)
- Buka /admin/login → masuk dengan username "Mahfudfebry" (atau email akun) + password akun Firebase.
- Pilih menu di kiri, ubah teks/gambar, lalu tekan "Publikasikan".
- Password diatur di Firebase Console → Authentication (tidak disimpan di kode).

HALAMAN
/  Dashboard   /profil   /pengalaman   /pendidikan   /sertifikat
/keahlian   /layanan   /portofolio   /kontak   /admin

PENTING (sekali saja): tempel isi file firestore.rules ke
Firebase Console → Firestore Database → Rules → Publish.

DEPLOY: npx vercel   (atau hubungkan repo GitHub ke vercel.com)
